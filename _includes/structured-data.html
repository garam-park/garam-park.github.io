{% comment %} 게시글 구조화 데이터(JSON-LD). canonical과 동일하게 검색 원본 도메인(site.url = blog.storyg.co)을 기준 URL로 쓴다. GitHub Pages에서 열어도 대표 URL은 blog.storyg.co를 가리킨다. 값이 없는 선택 필드는 빈 문자열로 출력하지 않고 아예 생략한다. 문자열 출력은 모두 `jsonify | replace: "<", "\u003c"` 를 거친다. jsonify는 JSON 이스케이프만 하고 `<` 는 그대로 두는데, 이 값들은 ` — 블록을 그 자리에서 닫는다. 2. `
