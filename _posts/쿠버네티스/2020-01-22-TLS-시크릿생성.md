---



**시크릿 생성**

``` bash
kubectl create secret tls [이름] --key [비밀키] --cert [인증서/공개키]
```

**시크릿 생성 예시**

``` bash
kubectl create secret tls secret-name --key path/to/private.key --cert path/to/certificate.crt
```
